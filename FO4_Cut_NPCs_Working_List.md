# Fallout 4 — Cut / Unused NPCs: Working Document

> **Purpose:** Track all known cut and unused NPCs from Fallout 4 and its DLCs.
> **Status:** 🚧 Work in Progress — entries added as sources are verified.
> **Last Updated:** 2026-06-02

---

## 📋 How to Use This Document

- **Source column** tracks where the entry was found — prioritise game files over wikis
- **DLC column** uses standard prefixes: `FH` = Far Harbor, `NW` = Nuka-World, `AT` = Automatron, `VT` = Vault-Tec Workshop, `WW` = Wasteland Workshop, `CW` = Contraptions Workshop
- **Form ID:** `xx` = DLC load order placeholder (e.g. `xx038B33`)
- **Status key:**
  - ✅ Verified — confirmed in game files
  - ⚠️ Partial — missing Editor ID or Form ID
  - ❓ Unverified — found in secondary source only
  - 🔴 Needs Research — significant gaps
