# Fallout 4 Cut Content Presets

LooksMenu character presets restoring cut content NPCs from Fallout 4 and its DLC.

Published by [Viable Dahlia](https://www.nexusmods.com/profile/viabledahlia) - Part of the **Cut Content Restored** modding project.

|---|---|---|---|
| [Gilda Broscoe](./gilda-broscoe/) | Far Harbor | [105463](https://www.nexusmods.com/fallout4/mods/105463) | ✅ Released |

---

## Requirements

All presets require [LooksMenu](https://www.nexusmods.com/fallout4/mods/12631) by Expired6978.  
No other dependencies unless noted in the individual preset's README.

---

## Installation

1. Install LooksMenu via your mod manager
2. Copy the `.json` preset file to:  
   `Data/F4SE/Plugins/F4EE/Presets/`
3. In-game: visit a surgeon, use a LooksMenu-enabled mirror or open console (`~`), type `slm 14`, go to the **Presets** tab
